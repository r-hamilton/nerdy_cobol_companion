# nerdy_cobol_companion
This is a step-by-step guide to assembling the Nerdy Cobol, and (for the most part) the Fortran. It augments the official nerdy gurdy 2.0.0 manual in a few ways:

- Keeps track of you progress 
- Warns you about steps that have prerequisites that haven't been completed
- Sets optional gluing/clamp timers for the steps that use glue, and alerts you when done
- Provides a more comprehensive tool list
- Suggests products to use for staining finishing, as well as their compatibility with each other and cleanup.
- Adds a few missing steps from the official manual, and gives more context for where the manual is sparse
- Rearranges a few things to make it more obvious what you can work on while other steps are drying/curing/etc.

Hopefully this can make the process of assembling your gurdy even more enjoyable.
